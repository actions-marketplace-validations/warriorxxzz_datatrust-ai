# Security Policy

## Supported Versions
Only the latest version (v2.3.0+) is actively supported with security updates.

## Reporting a Vulnerability
Please do not open public issues for security vulnerabilities. 
Instead, please report them via GitHub Security Advisories or contact the maintainer directly at warriorxxzz8@gmail.com. 
We will acknowledge receipt within 48 hours and provide a timeline for a fix.
